# Contributing corrections and extensions

This is a source-grounded teaching and briefing project. Contributions are
most useful when they make attribution, evidence, or institutional design more
precise.

## A strong correction includes

1. the file and statement at issue;
2. the primary source URL and stable section, paragraph, chapter, or revision;
3. the source text or data needed to evaluate the correction;
4. the proposed epistemic label;
5. whether the correction affects the dashboard, a source brief, a course
   module, or an event brief.

## Epistemic labels

Use one of:

- observed fact;
- source claim;
- scenario;
- recommendation;
- synthesis;
- question.

Do not rewrite a scenario event as an observed fact or attribute the DAPPR
framework to any source author.

## Proposed additions

New readings and cases should explain:

- which missing voice or analytical gap they address;
- which week or sourcebook chapter they strengthen;
- whether the source is primary, peer-reviewed, institutional, journalistic,
  or commentary;
- what existing conclusion it could change.

## Privacy and rights

Do not submit private student work, non-public community data, credentials, or
long copyrighted excerpts. Link to primary material and quote only what is
necessary for commentary or teaching.
